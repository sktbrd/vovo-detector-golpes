# Daily Improvement Report - 2026-03-10

## O que foi feito

**Melhoria:** Correção crítica de SEO - domínio no JSON-LD + Breadcrumb Schema

Corrigi um bug crítico onde todos os posts do blog estavam usando o domínio antigo `vovodetector.com.br` no structured data (JSON-LD) ao invés de `detectordegolpes.com.br`. Também adicionei Breadcrumb Schema para melhorar a aparência nos resultados de busca do Google.

### Mudanças implementadas:

1. **Correção de domínio no Article Schema:**
   - Substituído `https://vovodetector.com.br` → `https://www.detectordegolpes.com.br`
   - Atualizado em: logo, author.url, publisher.url, mainEntityOfPage
   - Criado variável `baseUrl` para centralizar o domínio (evitar bugs futuros)

2. **Adicionado Breadcrumb Schema:**
   - Estrutura de navegação: Home → Blog → [Post Atual]
   - Melhora SEO e exibição nos resultados de busca (rich snippets)
   - Ajuda Google entender hierarquia do site

3. **Refatoração de código:**
   - Extraído `baseUrl`, `currentUrl`, `logoUrl` em variáveis
   - Separado `articleSchema` e `breadcrumbSchema` para melhor organização
   - Dois scripts JSON-LD ao invés de um (padrão Schema.org)

### Impacto:

- ✅ **Crítico**: Bug de domínio incorreto estava prejudicando SEO de TODOS os 25 posts
- ✅ **Alto impacto SEO**: Breadcrumb schema melhora CTR nos resultados
- ✅ **Rich Snippets**: Google pode mostrar breadcrumbs nos resultados de busca
- ✅ **Consistência**: Nome "Detector de Golpes" ao invés de "Vovó Detector"
- ✅ **Futuro-proof**: Código mais fácil de manter (variáveis centralizadas)

### Por que essa melhoria é importante:

**SEO Critical:**
- Domínio incorreto no JSON-LD confundia Google sobre qual o site real
- Breadcrumb schema é fator de ranqueamento + melhora CTR
- Structured data correto = melhor entendimento do conteúdo pelo Google

**Exemplo do JSON-LD gerado:**

```json
// Article Schema
{
  "@context": "https://schema.org",
  "@type": "Article",
  "publisher": {
    "url": "https://www.detectordegolpes.com.br" // ANTES: vovodetector.com.br
  },
  "mainEntityOfPage": {
    "@id": "https://www.detectordegolpes.com.br/blog/como-identificar-golpe-no-pix"
  }
}

// Breadcrumb Schema (NOVO)
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"position": 1, "name": "Home", "item": "..."},
    {"position": 2, "name": "Blog", "item": "..."},
    {"position": 3, "name": "Como Identificar Golpe no Pix", "item": "..."}
  ]
}
```
